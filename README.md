## Note Manager App

Objective

Create a text-based Note Manager in Java that allows users to add, view, edit, delete, and search notes using File I/O and exception handling. The app helps users learn data persistence using files.


---

Features

1. Add Note – Add a new note to notes.txt.


2. Display Notes – View all saved notes in a numbered list.


3. Edit Note – Update an existing note.


4. Delete Note – Remove a note by its number.


5. Search Note – Search notes by keyword.


6. File-based Storage – All notes are saved in a text file.


7. Exception Handling – Handles file not found and I/O errors gracefully.




---

Tools Used

Java JDK 

VS Code / Terminal



---

How to Run

1. Save the Java file as notes.java.


2. Open terminal or VS Code integrated terminal.


3. Compile the program:



javac NoteManagerApp.java

4. Run the program:



java NoteManagerApp

5. Use the menu to add, view, edit, delete, or search notes.

Exception Handling – Use try-catch blocks for I/O operations.

Lists – Temporarily store notes in memory for editing and deleting.
